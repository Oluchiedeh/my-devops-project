# Azure VM Deployment with Terraform

This project demonstrates how to provision an Azure Virtual Machine using Terraform.

## Tools Used
- Terraform
- Azure

- ## Features
- Resource Group
- Virtual Network
- Subnet
- Network Security Group
- Attach the NSG to the subnet
- Public IP
- Network Interface
- Linux VM
- Outputs
